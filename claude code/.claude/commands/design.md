# デザイン作業モード

デザイン関連の作業を始めます。以下のツールとドキュメントを参照してください。

## 利用可能な Google Design MCP ツール

| ツール | 用途 |
|---|---|
| `generate_color_scheme` | ブランドカラー（HEX）→ Material Design 3 カラースキーム生成 |
| `search_icons` | キーワードで Material Symbols / Material Icons を検索 |
| `icons_instructions` | Material Icons の Web 実装手順を取得 |
| `search_fonts` | カテゴリ・言語で Google Fonts を検索 |
| `describe_font` | フォントのスタイル・ウェイト・用途を詳細解説 |

## デザイン作業の進め方

1. **カラー設計** → `generate_color_scheme` にブランドカラーを渡してスキームを作成
2. **フォント選定** → `search_fonts` でカテゴリ検索 → `describe_font` で詳細確認
3. **アイコン選定** → `search_icons` でキーワード検索 → `icons_instructions` で実装方法確認
