# YouTube 取得スキル

`tools/youtube/yt.py`（yt-dlp ラッパー）で YouTube の情報を直接取得する。**推測で答えず、必ずこのツールで実データを取る。**

コマンドは**プロジェクトルート（`/Users/itsukinino/portfolio/claude code`）を作業ディレクトリにして、下記の相対パス形のまま**実行する（許可設定がこの形に紐づいており、変形すると毎回確認を求められる）。

## サブコマンド

| 用途 | コマンド |
|---|---|
| 動画の基本情報 | `python3 tools/youtube/yt.py info <URL or ID>` |
| 字幕（文字起こし） | `python3 tools/youtube/yt.py transcript <URL or ID>` |
| キーワード検索 | `python3 tools/youtube/yt.py search "キーワード" -n 10` |
| チャンネル/再生リスト一覧 | `python3 tools/youtube/yt.py channel @handle -n 20` |

主なオプション:
- `transcript --timestamps` — 30秒区切りでタイムスタンプ付き（引用箇所を示す時・チャプター相当が欲しい時）
- `transcript --lang ja` — 言語を明示指定（既定は 手動字幕 → 動画の原語の自動字幕 → 希望言語の自動字幕 の順）
- `transcript --print full` — 全文を標準出力に出す（短い動画のみ）
- `info --full-description` — 概要欄を省略せず全文
- `--cookies-from-browser chrome` — 年齢制限・限定公開の動画（全サブコマンド共通、`info` などの前に置く）

## 進め方

1. **動画1本を要約/分析する時**: まず `info` でタイトル・長さ・字幕の有無を確認 → `transcript` で本文を取る。
2. **字幕は既定でファイル保存され、冒頭2000文字だけ表示される**。`tools/youtube/.cache/<id>.<lang>.txt` に保存されるので、長尺動画は全文を標準出力に流さず、**Read で必要部分だけ読む／Grep でキーワードを絞る**。長い動画ほどこの方が確実で速い。
3. **調査目的**: `search` で候補を並べ、再生数・投稿日・チャンネルを見て有望なものだけ `transcript` する。全部の字幕を取りに行かない。
4. **要約するときは動画URLとタイトルを添える**。タイムスタンプ付きで取った場合は引用箇所の時刻も示す。

## 注意

- 自動字幕は誤変換がある（固有名詞・数字は特に）。**数字や商品名を根拠にする時は「字幕ベースなので誤りの可能性あり」と明示する**。
- 短時間に大量の動画を叩くと HTTP 429 になる。連続取得は数本ずつに留め、429 が出たら少し待つ。
- 字幕が無い動画は `transcript` が失敗する。その場合は `info` の概要欄・チャプターで代替し、「字幕が無いので概要欄ベース」と断る。
- 動画・音声のダウンロードはこのツールでは行わない（字幕とメタデータのみ）。
