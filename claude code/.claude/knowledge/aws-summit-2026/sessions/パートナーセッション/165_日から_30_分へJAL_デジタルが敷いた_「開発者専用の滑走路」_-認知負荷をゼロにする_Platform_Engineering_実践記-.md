## p.10

解決策①— 社内文書TechDocs 化
開発者ポータルを入口として既存ドキュメントを集約
散らばった知識を、一つの入口に
AI と連携した対話的ナレッジ基盤を目指す
「探す」から、「聞く」へ(期待効果：ドキュメント探索時間ゼロ)
大量の散らばった文書を一つの「入口」に集約する。


## p.11

解決策②— Software Template 作成
申請から環境構築までを「数分」に短縮。
AWS LambdaとAmazon DynamoDBを自動払い出し
社内で採用されやすく、シンプルなパターンから
リポジトリ作成～Terraform 起動までを自動化
CI/CDの認知負荷削減
