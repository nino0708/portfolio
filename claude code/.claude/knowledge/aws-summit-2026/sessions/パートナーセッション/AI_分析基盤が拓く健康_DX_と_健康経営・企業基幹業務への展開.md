デモンストレーションの目的
健康データを「見える化」で終わらせず、
現場の判断・行動につなげる生成AIの使い方を具体的にお見せします

デモンストレーションの目的
ポイントは３つです
1.
全体像をどう把握するか（ダッシュボード）
2.
疑問が出た瞬間にどう深掘りできるか（AIエージェント）
3.
分析結果が具体的なアクションにつながっているか
