FinOpsの進めかた
Operate
運用
FinOps
3つのフェーズ
TIPS: 
•
まずは基本の情報収集で、全体の可視性を上げる
•
難易度の低いところから取り組み、成功事例を積み上げる（1→3）
•
運用レベルに落とし込んで、定常業務に組み込む
•
Inform
1. 可視性を向上させる
2. コスト配分とレポーティング
3. TCOの分析、ユニットエコノミクスの監視
•
Optimize
1. 無駄の削減
2. サイズ、レートの最適化（コスト = サイズ x レート）
3. オートスケールの活用、レート最適化の自動化
•
Operate
1. 基本的な予算と予測、ポリシーの策定
2. アラート、異常検出、レポートのプロアクティブな監視
3. ビジネス目標を含んだリアルタイムの予算管理/予測、
最適化の自動実行
