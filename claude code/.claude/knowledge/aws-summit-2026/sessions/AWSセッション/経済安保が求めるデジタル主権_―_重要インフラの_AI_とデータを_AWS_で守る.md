## p.21

CLOUD Act とは
• 2018年制定。重大犯罪捜査において、米国の法執行機関がサービスプロバイダーに電子データ
の提供を求めることを可能にする法律。米国で事業展開するすべてのクラウドプロバイダーに
適用（米国企業に限らない）
AWS の技術的保護
• Nitro System：オペレータアクセスがゼロの設計（NCC Groupが独立検証済み）
• カスタマーマネージドキーによる暗号化→AWSが復号キーを持たない。
• CLOUD Act は復号を強制する権限がない→暗号化されたデータは復号キーなしでは無価値
AWS の法的保護
• 法的に有効かつ拘束力のある命令がない限り、データを開示しない。過度に広範・不適切な要
請には異議を申し立てる
• 企業のお客様のデータ要請時は、法執行機関にお客様への直接連絡を促す
実績
• 米国外に保存されている企業/政府のコンテンツデータが米国政府に開示された事例は、2020年
の報告開始以降ゼロ
CLOUD Act
Clarifying Lawful Overseas Use of Data (CLOUD) Act
「米国法で日本のデータが開示されるリスクはあるか？」→ 技術的・法的に極めて低い
