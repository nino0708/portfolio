## p.80

80
クラウドとインターネットの繋ぎ⽅には２つの設計原則がある。
• クラウドからインターネットへ出ていく通信を集約することで
コストの最適化と検査ポリシーの⼀元管理ができる。
• インターネットからクラウドへ⼊ってくる通信を分散させることで
システムの特性に合わせたサービス選択ができる。
既存システム・現在検討中のアーキテクチャが設計原則に基づいているかを
ご確認ください。
