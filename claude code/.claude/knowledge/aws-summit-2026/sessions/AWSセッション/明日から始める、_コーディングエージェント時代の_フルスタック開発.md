## p.35

Agent Steering : Agent Block
Blocks 単位で用意された Steering File
使うべきとき:
チャットボット、コパイロット、データ抽出、または LLM  を活用するあらゆる機能。
マルチターン会話、Zod スキーマによるツール呼び出し、複数のモデルプロバイダーに対応。


## p.36

Agent Steering : Agent Block
Blocks 単位で用意された Steering File
使うべきでないとき
ツールや会話履歴を必要としない単純なテキスト生成。
