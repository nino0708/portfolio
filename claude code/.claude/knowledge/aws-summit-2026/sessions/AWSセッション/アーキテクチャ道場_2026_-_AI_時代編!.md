お題1 – AI ショッピングアシスタント

AI ショッピングアシスタントを導入します。ユーザーは自然言語で「夏の
キャンプに合うアウトドアウェアを探して」「これは洗濯機で洗える？」
といった質問ができ、エージェントが商品カタログ・レビュー・商品仕様を
横断して回答します。
数%のユーザーに対して行ったアルファテストでは、応答品質について良好

分かりました。そこでA 社は、応答品質をできるだけ維持しながら、コスト
とレイテンシを制御できるアーキテクチャを求めています。
あなたはこのAI ショッピングアシスタントをどのように設計しますか？

## p.9

お題1 – AI ショッピングアシスタント
アルファテストの結果と本番リリースの目標
•
実際のユーザー発話サンプルから評価セットを作成し、Claude Haiku で目標水準をクリアした
•
商品検索：約30%、商品詳細の質問：約25%、注文・配送の質問：約20%、曖昧な相談：約15%、その他：約10%
•
このアルファテストでの評価結果から、10%程度の応答品質スコアの低下は許容する
•
リクエストあたりの推論コストの目標を以下とする
•
客単価(5000 円) x 購入率(3%) x 利益率(5%) x AI の効果(12% 〜30%) = 0.9 〜2.25  円/セッション
•
1 セッションあたり3 往復が中央値だとすると0.3 〜0.75 円/request →目標は0.5 円/request
•
Prompt Cache を考慮しても、Claude Haiku で2.43 円(4.9倍) となり目標を超過
•
初回応答レイテンシ(Time to first token, TTFT) の目標を、P50 で3 秒未満とする
