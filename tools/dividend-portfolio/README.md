# 高配当株ポートフォリオ 月次買付アシスタント

毎月届く「日本株高配当株ポートフォリオ推奨表」と自分の保有状況から、
**その月に何を何株買えばいいか**を出す。

## 使い方（毎月上旬）

1. Claude Code に **推奨表のスクショ**と**管理シートのスクショ**を貼る
2. `data/recommended_YYYY-MM.json` と `data/holdings_YYYY-MM.json` が作られる
3. 株価を取得して計算する

```bash
python3 fetch_prices.py                       # Yahoo Finance から最新株価
python3 allocate.py --month 2026-08 --budget 28000
```

投資額が変わる月は `--budget` を変えるだけ。

## 優先順位（この順で効く）

1. **ディフェンシブ / 景気敏感 を 50:50** ← 最優先。予算の振り分けで担保する
2. **セクターの金額を均等に** ← 少ないセクターから水位を上げる（water-filling）
3. **セクター内で企業の金額を均等に** ← 同上

保有株は売らない前提なので、既に水位より上のセクター・銘柄は「今月見送り」になる。
株数は総当たりで、目標額に一番近い組み合わせを選ぶ（＝「四捨五入で条件に近い方」）。
無理に予算を使い切るとバランスが崩れるので、端数は繰り越す。

## データファイル

| ファイル | 中身 | 更新 |
|---|---|---|
| `data/recommended_YYYY-MM.json` | その月の推奨表36銘柄 | 毎月（差分比較用に残す） |
| `data/holdings_YYYY-MM.json` | 保有銘柄と株数 | 毎月 |
| `data/prices.json` | 全銘柄の株価 | `fetch_prices.py` で自動 |
| `data/classification.json` | 業種 → ディフェンシブ/景気敏感 | 変わった時だけ |
| `data/lots.json` | 1株単位で買えない銘柄 | 変わった時だけ |

### classification.json の根拠

管理シートの「銘柄構成比」ツリーマップから業種→区分を逆算した。
保有31銘柄で評価額 **景気敏感56.32% / ディフェンシブ43.68%** を再現でき、
シート表示の 56.3% / 43.7% と一致するので、対応は正しいとみなしている。

推奨表にしか出てこない業種（精密機器・金属製品・ゴム製品・J-REIT市場）は
シートに実例が無いため東証33業種の一般的な扱いから推定した。`inferred` に列挙してある。
**この4業種の銘柄を実際に買う月が来たら、シート側の区分を確認して確定させること。**

### lots.json

SBIのS株・楽天のかぶミニは国内ETF/REITが対象外なので、ETFは通常の売買単位が要る。
- `1343 NF・J-REIT ETF` … 10口単位
