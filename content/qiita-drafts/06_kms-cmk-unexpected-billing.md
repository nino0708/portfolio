# KMSのカスタマーマネージドキーを放置したら月12,000円請求された話

<!-- tags: AWS, KMS, コスト管理, 課金, 失敗談 -->
<!-- status: 下書き -->

## 何が起きたか

学習目的で AWS KMS のカスタマーマネージドキー（CMK）を作成して、そのまま削除も無効化もせずに放置していた。
翌月の請求を見たら **約12,000円** が発生していた。

---

## KMS の料金体系（落とし穴）

| 料金タイプ | 金額 | 注意点 |
|---|---|---|
| CMK の月額料金 | **$1/キー/月** | 使っていなくても発生する |
| API リクエスト料金 | $0.03/10,000リクエスト | 使った分だけ |

**CMK は存在しているだけで課金される。**

AWS マネージドキー（`aws/s3` など）は無料だが、自分で作ったキーは使っていなくても毎月料金がかかる。

---

## 気づかなかった理由

- 学習環境で作成した CMK を「どうせ無料枠内だろう」と思い込んでいた
- CMK の月額課金は使用量と関係なく発生するため、コスト分析で気づきにくい
- 複数キーを作っていたため合計金額が膨らんでいた

---

## AWS サポートに問い合わせた結果

請求に気づいた翌日、AWS サポートに問い合わせ。

**結果：返金してもらえた。**

初回であること・学習目的であること・すぐに対処していることを伝えると、好意的に対応してもらえた。ただしこれは必ずしも保証されるものではない。

---

## 再発防止策

### 1. CMK を使い終わったら即座に削除または無効化

削除には 7〜30 日の待機期間があるため、すぐ削除予定にする。

```bash
aws kms schedule-key-deletion \
  --key-id <key-id> \
  --pending-window-in-days 7
```

### 2. AWS Budgets でコストアラームを設定する（最重要）

```
AWS Budgets → 予算を作成 → コスト予算
月 $10 を超えたらメールで通知
```

学習環境でも最低限 $10 のアラームは設定しておく。

### 3. Cost Explorer で KMS の費用を定期確認

サービス別フィルターで KMS の費用を月1回確認する習慣をつける。

---

## CMK が必要かどうかの判断基準

| ケース | 使うキー |
|---|---|
| S3 の標準暗号化 | AWS マネージドキー（無料） |
| 監査・コンプライアンス要件あり | CMK（有料） |
| 学習・検証目的 | AWS マネージドキーで十分 |

学習目的なら CMK を使う必要はほぼない。

---

## まとめ

- CMK は存在するだけで月 $1/キー の課金が発生する
- 使い終わったら即削除スケジュールを設定する
- AWS Budgets のコストアラームは学習環境でも必須
