# 月刊AWS ネタ帳

月刊AWSは月1本。構築課題は「問題」と「回答」を1ヶ月ずつ交互に出す（偶数月が問題、奇数月が回答）。
問題を出す月の記事とテーマをそろえて、準備を使い回す。

## 各テーマのメモ

- **どの資格から取る？**：CLF → SAA → SOA → DVA → SAP の体験談。勉強時間と使った教材
- **1時間で自分のWebサイトを公開**：portfolio の S3 + CloudFront 構成をそのまま実例に使える
- **このシステム、月いくら？**：AWS料金計算ツール（Pricing Calculator）を使ったクイズ形式。コスト感覚を身につける
- **ポチポチ卒業：Terraform入門**：手作業で作ったものをコードにする体験
- **わざと壊してみよう**：EC2を止める、SGを閉じる → 気づく、切り分ける、直す、振り返る。障害対応の型を体験する
- **AWSの調べ方と無料教材まとめ**（提案）：公式ドキュメント、Black Belt、Skill Builder、ハンズオン資料の使い分け。新年度の前に「自分で調べられる人」を増やす
- **サーバーレスってなに？**（提案）：portfolio の問い合わせフォーム（API Gateway → Lambda → DynamoDB / SES）を実例に、「サーバーを持たない」を説明する
- **消したらどうする？バックアップ入門**（提案）：S3バージョニング、EBSスナップショット、AWS Backup。6月の課題5の解説も兼ねる
- **誰がやっても同じ結果に：手順書の書き方**（提案）：航空整備の手順遵守とダブルチェックの考え方を運用に持ち込む。8月の「わざと壊してみよう」の後なので、復旧手順書の話につなげやすい
