# aws-education

AWSの後輩・新人育成（後進育成）について、相談しながら方針を決めたり教材を作ったりする場所。

## 方針（たたき台）

- **ハンズオン → 検証 → 資格** の順で学ぶ。資格は後からついてくる
- 運用・保守の現場で使える力を優先する（監視、障害対応、変更管理、コスト）
- 作業は手順書にまとめ、IaC（Terraform）で再現できる形にする
- 障害対応は「異常検知 → 切り分け → 報告 → 復旧 → ポストモーテム」の型で身につける
- ダブルチェックと記録管理を徹底する（航空整備の現場で学んだ考え方を持ち込む）

## フォルダ構成

| フォルダ | 中身 |
|---|---|
| `curriculum/` | 育成ロードマップ・カリキュラム |
| `materials/` | 研修資料・ハンズオン手順書・演習問題 |
| `consultations/` | 相談ログ（決めたこと・宿題を残す） |

## 相談ログの書き方

`consultations/_template.md` をコピーして `YYYY-MM-DD_テーマ.md` という名前で保存する。

## 注意

- このリポジトリは **public**。受講者の実名・評価、社内情報、AWSアカウントIDや認証情報は書かないこと
- リポジトリ直下のTerraformとは関係ない（このフォルダには `.tf` ファイルを置かない）
