# Tempus 仕様（合意済み・2026-08-24）

二瀬樹 専用の業務効率化ツール。本業・副業・生活・学習を1箇所に集約する。
共有は「プロジェクト単位」で、土台(RLS)だけ先に入れUIは後回し。

## 決定事項

| 項目 | 決定 |
|---|---|
| 基盤 | Supabase 無料枠（Postgres + Auth + Realtime） |
| ログイン | Google のみ（カレンダー連携に必須） |
| フロント | React + Vite + TypeScript の PWA / Cloudflare Pages |
| スケジュール | 時間割型（タイムブロッキング） |
| カレンダー | Google が予定の正・双方向。v1は読み取りのみ、書き戻しはv2 |
| 置き方 | 自動提案 → 人が承認（完全自動にはしない） |
| 起票の必須項目 | タイトルだけ。見積もりは推定で仮入れ、重要度は mid |
| 起票口 | ①LINEに一言 ②アプリ内の常時1行入力欄 ③ホーム画面から1タップ |
| 実績時間 | 開始/終了の時刻を記録して差分。裏でタイマーは回さない |
| 通知 | 高頻度=Webプッシュ / 少数の重要=LINE |
| 本業データ | 匿名化して入れる（顧客名・システム名・手順の中身は書かない） |
| オフライン | 見る＋起票のみ。編集・完了はオンライン時 |
| Notion | Tempusに一本化。稼働中タスクのみ初回移行、旧DBは残置 |
| 既存アプリ | Valetudoのみ取り込む(v2)。小口現金・会計は取り込まない |

## 制約（調査済みの事実）

- Supabase Free は**課金が発生しない**。超過＝サービス制限（停止/読み取り専用/402）。Spend Capは有料専用
- Supabase Management API に **usage/invoice/quota エンドポイントは無い** → 使用量は自前で測る
- 無料枠: DB 500MB / ファイル1GB / 通信5GB月 / MAU 5万 / Edge関数50万回 / 2プロジェクト / 7日未使用で停止
- **通信5GBは測れない** → 画像・添付をSupabaseに置かない、リアルタイム購読は開いている画面だけ
- LINE Notify は 2025-03-31 終了。Messaging API を使う
- LINE 無料は月200通だが、**応答メッセージ(reply)はカウント対象外** → LINE起票+返信は無料無制限
- 止め忘れ対策: 見積もりの3倍 or 4時間超で終了時に確認を出す

## v1 の範囲

起票3口 / タスク一覧 / 今日の時間割(Google読み取り) / 自動提案→承認 / 実績記録
