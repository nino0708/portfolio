# ドリンク代計算

飲み会・宴会の**必要なお酒の本数・種類の割合・費用の概算**をサッと出す、幹事向けの単独ツール。
もともと会計ソフト（accounting-app）の「宴会お酒計算」タブだったものを、独立したアプリとして切り出したもの。

## 使い方

`index.html` をブラウザで開くだけ。サーバー不要・完全にオフラインで動作する単一HTMLファイル。

```
open index.html          # Mac
```

## 入力

| 項目 | 説明 |
|---|---|
| 参加人数 | 必須 |
| 所要時間 | 宴会の長さ（標準 2〜2.5時間） |
| 飲むペース | 控えめ / ふつう / しっかり飲む |
| 顔ぶれ（構成） | バランス / ビール党多め / サワー党多め |
| 価格帯 | 節約 / 標準（スーパー） / ちょっと良い |

## 出力

- 総杯数・1人あたり杯数・1人あたり純アルコール量
- 種類ごとの提供割合（ドーナツグラフ）・必要杯数・用意する量・概算費用
- 炭酸水・ソフトドリンク・氷など割りものの目安
- 合計の概算費用（1人あたりも表示）

入力内容はブラウザの `localStorage`（キー `partyCfg`）に自動保存される。

## 単価・計算の根拠

- 缶ビールは参加人数の約1.5倍が適量、2杯目以降はハイボール/酎ハイ・サワーへ（懇親会発注ガイド）
- 飲み放題の平均は1人5杯前後、宴会の標準は約2〜2.5時間（居酒屋データ）
- 「節度ある適度な飲酒」は純アルコール20g/日が目安（厚生労働省 健康日本21）
- 単価は標準＝スーパー相場を基準に、価格帯で増減

いずれも概算。実際の飲酒量・価格は年代・性別・好み・店舗で変わる。
